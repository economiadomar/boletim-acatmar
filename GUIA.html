📖 Boletim ACATMAR — Guia de atualização

Como funciona o folheador digital e como publicar um novo boletim a cada 6 meses.

Como está organizado

A pasta boletim acatmar contém tudo o que é publicado:

boletim acatmar/
├── index.html          → página com todas as edições (capa do site)
├── viewer.html         → o folheador (efeito de virar página)
├── editions.json       → LISTA das edições (é aqui que você adiciona uma nova)
├── assets/lib/…        → biblioteca do efeito de folhear
└── editions/
    ├── 2025-1/
    │   ├── pages/p-1.jpg … p-8.jpg   → cada página do boletim, em imagem
    │   ├── cover.jpg                 → miniatura da capa
    │   └── boletim.pdf               → PDF original (botão "Baixar PDF")
    ├── 2024-2/…
    └── 2024-1/…

Publicar um novo boletim (a cada 6 meses)

Quando o novo PDF estiver pronto (ex.: 1º semestre de 2026):

  1. Crie a pasta editions/2026-1/pages/.
  2. Converta as páginas do PDF em imagens JPG dentro de pages/ (nomeadas p-1.jpg, p-2.jpg…). Veja o comando abaixo.
  3. Coloque o PDF original como editions/2026-1/boletim.pdf.
  4. Gere a miniatura editions/2026-1/cover.jpg (uma cópia menor da página 1).
  5. Adicione a edição no topo da lista em editions.json.
  6. Publique (arraste a pasta no Netlify — veja a última seção).
Jeito mais fácil: me mande o PDF novo e eu faço os passos 1 a 5 em segundos. Você só publica no Netlife no final.

Comando para converter o PDF (no Terminal do Mac)

Precisa do poppler instalado (brew install poppler). Com o PDF em ~/Downloads/boletim-2026-1.pdf:

cd "/Users/leandroferrari/boletim acatmar"
mkdir -p editions/2026-1/pages
pdftoppm -jpeg -jpegopt quality=82 -r 150 \
  ~/Downloads/boletim-2026-1.pdf editions/2026-1/pages/p
cp ~/Downloads/boletim-2026-1.pdf editions/2026-1/boletim.pdf
sips -Z 600 editions/2026-1/pages/p-1.jpg --out editions/2026-1/cover.jpg

Adicionar a edição em editions.json

Abra editions.json e cole um bloco novo no topo da lista editions (a mais recente aparece primeiro):

{
  "id": "2026-1",
  "title": "1º Semestre de 2026",
  "period": "I Semestre de 2026",
  "volume": "Vol. 4 · Ed. 1/26",
  "year": 2026,
  "semester": 1,
  "pages": 8,
  "highlights": ["Destaque 1", "Destaque 2", "Destaque 3"]
},
Não esqueça a vírgula no fim do bloco (separando do próximo). Se o site parar de carregar as edições, quase sempre é uma vírgula faltando ou sobrando aqui.
  • id — precisa ser igual ao nome da pasta em editions/.
  • pages — quantas páginas o boletim tem (pode ser diferente de 8).
  • highlights — as chamadas que aparecem no cartão da capa (opcional).

Testar antes de publicar

No Terminal, dentro da pasta do boletim:

cd "/Users/leandroferrari/boletim acatmar"
python3 -m http.server 8791

Depois abra http://localhost:8791 no navegador. Pare o servidor com Ctrl+C.

Publicar no Netlify

  1. Entre em app.netlify.com.
  2. Arraste a pasta boletim acatmar inteira para a área de deploy (ou atualize o site existente).
  3. Pronto — o link é o mesmo para mandar aos associados por WhatsApp/e-mail.
Cache: se você trocar uma imagem mantendo o mesmo nome, o navegador pode mostrar a versão antiga. Para páginas de uma nova edição isso não acontece, porque o nome da pasta muda.
